# Problem 10: Storefront design

- **Yale visual system:** Added a consistent Yale blue, white, warm stone, and restrained Yale-gold palette so the site feels collegiate and trustworthy while keeping product photography prominent.
- **Editorial storefront hierarchy:** Added display typography, eyebrow labels, generous spacing, product-card hover states, and a more confident detail-page layout so shoppers can scan quickly and feel the collection has a point of view.
- **Interactive product viewing:** Added a click-to-zoom product image on detail pages. Customers can inspect garment details before deciding, which makes the catalogue feel more like a real premium storefront.
- **Motion and personality:** Added gentle entrance and hover motion plus a CSS bulldog mascot near the concierge. The movement creates polish and the mascot gives Campus Customs a memorable, friendly campus character without distracting from shopping.
- **Shoppable account and bag flow:** Reworked the account screens as editorial split layouts and carried the product imagery into the bag. Selectable size tiles, a clear add-to-bag action, and visible bag thumbnails make the journey feel like a complete storefront instead of a form demo.
- **Reliable visual concierge:** The packaged site embeds catalogue imagery and presents matching pieces as compact image-led chat cards, so the concierge stays useful and visually consistent even when a backend server is not running.

These changes are concrete in the running app: they appear in the shared storefront styles, product cards, detail pages, and floating chat area.
